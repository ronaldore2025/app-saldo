# App de Monitoramento de Saldo no Meta Ads

Este App é usado para gerenciar campanhas de anúncios no Facebook e Instagram, monitorar saldos em tempo real e otimizar o desempenho das campanhas para pequenas e médias empresas.

## Funcionalidades
- Monitoramento automático do saldo das contas de anúncios.
- Alertas em tempo real quando o saldo está baixo.
- Integração com ferramentas de automação como Make e N8N.

## Como Funciona
O App utiliza a API do Meta Ads para acessar dados de saldo e campanhas, garantindo segurança e eficiência no gerenciamento de anúncios.
